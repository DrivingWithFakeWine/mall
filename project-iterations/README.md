## 一、项目是什么

一个前后端分离的商城 + 秒杀系统（JDK 25 / Spring Boot 4.1.1 / MyBatis-Plus / MySQL 8 /
Redis / RabbitMQ / React 19）。演进原则是**压测驱动**：先用基线暴露瓶颈，再引入对应技术，
改完用同一套 JMeter 计划复测，用数据判断是否有效。

## 三、三轮压测的核心结论

1. **闸门只在“请求远大于库存”时有效**：输家被 Redis 拦住，不再占用 DB 连接；
2. **全赢场景必须异步化**：每个请求都要写库，只能把突发从请求路径移走；
3. **分桶解决单行锁**：500 单并行落在 8 行，行锁等待峰值降到 1；
4. **异步只移走 DB 事务，不移走 HTTP 成本**：500 并发在 2C 上受理仍有 2.2s。

完整数字见 `2026-11-06/loadtest-results.md`，前两轮见仓库 `HANDOFF.md` 第 4.5 节与 `DECISIONS.md` 第 7 节。
